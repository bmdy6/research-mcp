## 京东价格与适配

真实 DOM 同时有突出显示的国补领后价，以及灰色未补贴标价。例如同一商品显示 5354.15 和 6399；适配只读取后者，不把国补领后价标成原价。没有可识别未优惠标价的卡片跳过；无法解析整页返回 `parse_error`。商品卡片没有普通商品锚点，使用同卡片客服链接中的公开 `pid` 构造 `https://item.jd.com/<pid>.html`，不携带客服链接的其他参数。

结果含 `price`（人民币金额字符串）和 `price_note: 页面标价，未含券/国补`。结果只能代表当时页面展示；不计算券、国补或最终结算价。

- 真实 Ego Lite 页面阅读：京东成功；淘宝导航被浏览器权限提示中断；其余未执行。

- 默认免费渠道不变；未启用本机访问也可运行其他渠道；本机渠道不进入 public provider allowlist。
