## 拼多多排查与限制

- 用户已登录。`search_result.html?search_key=...` 初始只有零宽字符；按正文变化等待（最多 12 秒）后中文、英文都能渲染，因此不能继续沿用“登录墙/只有空白”的旧结论。
- 中文卡片标题存在短片段，例如“优派KC98”“达尔”“前行”；可读取标价 111.88、225、143.4 等及券后/限件说明。英文卡片可读更长标题，但同样没有商品链接。
- 检查中文搜索卡片 DOM：没有商品 `a[href]`，也没有公开 `data-goods-id`、`goods_id` 或 `data-item-id`。正常滚动后仍无可导出的商品链接，不能从图片 URL 推断商品 ID。
- 尝试正常 `/search.html` 入口，跳到 `/portal.html?redirect_from=/search.html` 门户，未得到另一种可用搜索结果结构。未将个性化门户推荐当作搜索结果，也不提交门户/账户页内容。
- 本轮不接入拼多多。不用搜索页 URL 代替商品 URL，不猜 ID，不额外逐条点击详情收集链接；这超出 #15 的只读搜索页提取方式。以后页面若暴露稳定商品链接，可补接并重新双语验收。
- linux.do 按用户确认：需要邀请码，不接入，README 保持不支持。
